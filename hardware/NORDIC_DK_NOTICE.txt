The SKY65943_DK10171 and reference nRF9151_DK10171 footprints were extracted
locally from Nordic Semiconductor's nRF9151 DK hardware release 1.0.0,
PCA10171 board revision 1.0.1 / 400797.PcbDoc, using KiCad 10.0.7's Altium
importer. The reference nRF9151_DK10171 footprint is NOT the current U1
footprint. U1 still uses the separately attributed community footprint.
